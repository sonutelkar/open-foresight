`eodhd-symbol-lists.json` holds real EODHD `exchange-symbol-list` rows for AAPL (US), SAP (XETRA), NESN (SW) and VOD (LSE). `openfigi-isin.json` holds real OpenFIGI responses for their ISINs, recorded without an API key. Each response lists one candidate per trading venue, 166 to 303 of them. The file keeps at most six per ISIN and records the full count in `totalCandidates`. All candidates for one ISIN share one `shareClassFIGI`. EODHD terms govern redistribution of the symbol rows, so keep this repository private.
