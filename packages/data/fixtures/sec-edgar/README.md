# SEC fixture provenance

The JSON files are reduced excerpts of SEC responses for CIK 0000320193, captured on 2026-11-22. `submissions.json` contains the selected rows from `https://data.sec.gov/submissions/CIK0000320193-submissions-001.json`. `companyfacts.json` contains the two observations for `dei:EntityCommonStockSharesOutstanding` from `https://data.sec.gov/api/xbrl/companyfacts/CIK0000320193.json`.

The filing text files contain short text excerpts of the SEC documents, with whitespace normalized. They are not full raw SEC filings. The source documents are `https://www.sec.gov/Archives/edgar/data/320193/000119312509214859/d10k.htm` and `https://www.sec.gov/Archives/edgar/data/320193/000119312510012091/d10ka.htm`.
